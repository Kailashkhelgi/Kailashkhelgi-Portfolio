## 🛠️ Local Development
To run this portfolio locally:
```bash
# Clone the repository
git clone https://github.com/Kailashkhelgi/Kailashkhelgi-Portfolio.git

# Navigate to project folder
cd Kailashkhelgi-Portfolio

# Run using any static web server (e.g., Python)
python -m http.server 3000
```
Open `http://localhost:3000` in your web browser.
